# Disclosure Desk · 案件披露材料审查模块

接入现有 Vite + React + TypeScript 应用的本地模块，用于批量登记、归并、核对案件披露文书。无后端，刷新后通过事件日志重放恢复全部数据与完整轨迹。

## 本地运行

```bash
npm install
npm run dev        # 本地开发
npm test           # 30 项逻辑自检 + 9 个组件渲染冒烟检查
npm run build      # tsc + 生产构建
```

首次打开无数据时，左侧可点 **“一键载入演示案卷”**。建议核对路径：

1. 一键导入前三个演示包；
2. 打开「审查台」，确认 5 个阻断项：锚点歧义、冲突主张、遮挡重叠、反向区间、反向页码；
3. 分别合并重叠/相邻遮挡、撤回公开主张、交换反向区间起止页、确认倒序扫描翻转页码、逐版本指定锚点；
4. 进入「披露清单」生成并导出 Markdown；
5. 在「文书库」撤回合同价格保密主张，回到清单页可见旧清单立即标记 **“结论已失效”**；
6. 在导入弹窗中导入第 4 个包 `合同历史底稿.zip`，可见旧锚点处置因新增 v0 版本而重新打开；
7. 刷新浏览器，全部导入、处置、撤回、变更、生成记录仍在「操作轨迹」中。

## 业务规则

- **重复包自动归并**：按包内“显式文书 key/归一化标题 + 版本标签 + 哈希 + 页数”计算内容指纹；完全相同的包整体跳过，不重复新增文件、主张、遮挡。
- **乱序版本归并**：同名文书跨包归并；版本按语义版本/日期排序，不按到达顺序排列。更旧版本后到会生成信息提示，不阻断。
- **同标签异内容阻断**：同一版本标签下出现不同哈希文件时阻断，可将其中一个重新标记版本标签。
- **反向页码阻断**：文件页码标签整体递减时阻断；确认扫描倒序并翻转后解除。
- **区间核对**：起止页反向、超出总页数阻断；相邻遮挡只警告并可一键合并；重叠遮挡阻断，必须撤回或取并集合并。
- **同文件冲突主张阻断**：保护类主张（保密/特权/不予披露）与“不主张保密（公开）”覆盖同一页时阻断。多个保护类主张按并集处理；重复同型主张只提示。
- **跨版本锚点歧义阻断**：同一版本命中多个位置，或某版本找不到锚点，都必须逐版本指定；缺失版本可显式确认“该版本无此锚点”。后续新证据改变候选集合时，旧处置自动失效。
- **清单硬门禁**：只要存在 open 的 blocking 问题或没有任何文件，就不能生成披露清单。警告/信息不阻断。
- **撤回/变更立即失效**：任何主张或遮挡撤回、变更，相关问题处置和旧清单签名立即失效；不覆盖旧数据，只追加事件。

## JSON 导入结构

导入弹窗支持单包或数组：

```json
{
  "name": "对方材料包.zip",
  "exportedAt": "2026-09-01",
  "docs": [
    {
      "key": "contract",
      "title": "《采购框架协议》",
      "summary": "文件摘要",
      "versions": [
        { "label": "v2", "fileName": "合同.pdf", "sha": "hash", "pageCount": 20, "pageLabels": [1, 2] }
      ],
      "claims": [
        {
          "doc": "contract",
          "version": "v2",
          "ranges": [{ "from": 5, "to": 8 }],
          "type": "confidential",
          "basis": "价格条款",
          "assertedBy": "对方律师"
        }
      ],
      "redactions": [
        { "doc": "contract", "version": "v2", "ranges": [{ "from": 5, "to": 8 }], "note": "价格" }
      ],
      "anchors": [
        { "id": "art5", "doc": "contract", "label": "第五条 验收", "occurrences": [{ "version": "v2", "page": 7 }] }
      ]
    }
  ]
}
```

主张类型：`confidential`（保密）、`privileged`（特权/工作成果）、`withheld`（不予披露）、`public`（不主张保密）。

## 代码结构

- `src/disclosure/types.ts`：领域类型与事件定义；
- `src/disclosure/utils.ts`：区间运算、版本排序、内容指纹等纯函数；
- `src/disclosure/engine.ts`：导入归并、事件 reducer、问题分析、阻断门禁、披露清单与失效签名；
- `src/disclosure/commands.ts`：命令/事件工厂；
- `src/disclosure/store.ts`：localStorage 事件日志与重放；
- `src/disclosure/demo.ts`：覆盖全部核对场景的演示包；
- `src/disclosure/ui/*`：审查台、文书库、清单、轨迹与弹窗；
- `selftest/selftest.ts`：30 项纯逻辑场景；
- `selftest/ui-smoke.tsx`：React SSR 渲染冒烟检查。
